How it works

  • Pro only. Free pages keep starting on ₦2,000.
  • The server checks that the chosen amount is one of the page’s own amounts.
  • If that amount is later removed, or the page leaves Pro, the page goes back to today’s rule: the amount closest to ₦2,000.
  • Nothing changes about fees, the minimum or what the supporter pays.

Effort

Small: one stored choice, a server check, the Settings control and the tip form reading it, with tests. It would join the "Make it yours" work once you approve it.
