The rules

  • The same day Pro ends, the public page shows the standard page: Classic layout, today’s cover rules for Free, bio, up to 3 Free social links, standard amounts, and “Get your own TipMe page” comes back.
  • Nothing is deleted: theme, layout, sections, gallery photos, video links, services, events and the pinned note are all kept.
  • While lapsed, Page Studio opens read-only with the same Free teaser and a note that the design is saved.
  • The supporter wall hides with the rest; supporters’ choices are kept and still respected.
  • When Pro resumes, the last published Studio page returns. Any unpublished draft is kept as a draft.
  • Links and QR codes never change, so nothing printed breaks.

How long kept designs are held after Pro ends (forever, or a set time) follows whatever retention rule you set for other Pro data.
