Facts from the code

  • Free pages print one thing: the square card on A6 with 6 mm margins. Pro pages using a design choose one of 8 formats; the code is the server’s picture, only placed, never redrawn.
  • A Pro page using a free style (Purple, Night, Clean) gets the Free card, not the formats.
  • Print stays greyed out until the Pro design has been drawn. If the page lost Pro, it says the design is only a preview and can’t be printed.
  • On the Free card the link prints twice: once inside the card and again under it.
  • Indigo Grid here is an illustration of the agreed look; the real picture comes from the server.
