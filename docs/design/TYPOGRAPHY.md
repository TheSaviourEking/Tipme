# Typography

Typography has interface, editorial, brand, and numeric roles.

- Interface: crisp grotesk for controls, labels, and body copy.
- Editorial: high-contrast serif for selected headlines and human emphasis.
- Brand: compact heavy wordmark treatment.
- Numeric: tabular figures and stable currency widths.

Exact typefaces remain provisional under D-09 until rendered desktop/mobile specimens are approved. Evaluation must record licence, available glyphs including `₦`, loaded weights, byte cost, fallback metrics, and appearance with font loading disabled. Headline line breaks must survive long names and 200% zoom.
