# Iconography

Use text when it communicates more clearly. Visible brand symbols use authored SVG with a consistent 24-unit construction grid, optical alignment, rounded joins where appropriate, and current-color inheritance.

Conventional actions remain recognizable. Do not use a generic icon library as decoration, place every icon in a colored circle, or ship Unicode glyphs as final brand symbols. Symbols require accessible names when informative and `aria-hidden` when redundant with visible text.
